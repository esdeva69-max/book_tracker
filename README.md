# Movie Library — Личная кинотека

Автор: [Пасечник Елизавета Сергеевна]

## Описание программы

Movie Library — это графическое приложение для ведения каталога фильмов. Оно позволяет хранить информацию о просмотренных или желаемых к просмотру фильмах.
Приложение обладает следующими функциями:
*   **Добавление фильмов:** Ввод названия, жанра, года выпуска и рейтинга.
*   **Отображение списка:** Все фильмы видны в удобной таблице.
*   **Фильтрация:** Быстрый поиск по жанру и году выпуска.
*   **Сохранение данных:** Весь список можно сохранить в файл `movies.json`.
*   **Загрузка данных:** Возможность загрузить ранее сохранённый список.
*   **Валидация:** Программа проверяет корректность введённых данных (год — число; рейтинг — от 0 до 10).

## Пошаговая инструкция запуска
1.  Убедитесь, что у вас есть файлы `movie_library.py` и `README.md` в одной папке.
2.  Откройте терминал (командную строку).
3.  Перейдите в папку с проектом с помощью команды `cd путь/к/папке`.
4.  Запустите приложение командой:
    ```bash
    python movie_library.py
    ```
    После этого откроется окно программы.
